## Purpose

The previous task proves the technique once. This one makes it a habit by applying it to three task types in fast succession. The tight timebox is deliberate: it prevents polishing and surfaces which prompt pattern each person defaults to.

## Timing

| Phase | Minutes |
|---|---|
| Round 1, summarise | 4 |
| Round 2, rewrite | 4 |
| Round 3, structure | 4 |
| Comparison and short group round | 3 |

Call the time out loud at each switch and mean it. The exercise loses its character if rounds are allowed to run long.

## Scheduling

This adds fifteen minutes to Lesson 6, which then needs around seventy-five minutes in total. Plan for that rather than discovering it on the day.

If the afternoon is running late, this is the exercise to drop, because the previous task already demonstrates the technique. Be aware of what you are giving up: the repetition across different task types is what turns the technique into a habit rather than a demonstration.

## Common Issues

**People keep working past the buzzer.** The most common problem, and the one that destroys the format. Announce upfront that unfinished is expected and that stopping mid-flow is part of the design.

**All three rounds end up being the same task type.** Some participants pick three summarisation jobs. Check the material during round 1 and redirect, because the whole value lies in the contrast between the rounds.

**Round 3 falls flat.** Structuring needs genuinely messy input. If someone brings a tidy list, there is nothing to structure. Have a fallback ready, such as the collected notes from the Lesson 2 exercise.

**The room finds it too fast and superficial.** Concede the point and name the purpose: this is drilling, not production. The deep work happens in Lesson 7 with a single case.

## Discussion Points

- Which round was hardest, and why do you think that is?
- Which building block did you use in all three rounds?
- Where did iterating beat writing a longer prompt?
