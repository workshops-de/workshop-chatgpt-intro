## Overview

Time to open the settings. In twenty minutes you will configure the four things that separate a random chat window from a tool that fits your work: custom instructions, memory, data controls and a project.

Everything here works on a free account.

## Prerequisites

- A working account from the preparation task
- If you are using a company account, check with your admin which settings you are allowed to change

## Steps

### 1. Check your data controls first

Before you type anything real, open **Settings → Data Controls**.

- On a personal plan, decide whether "Improve the model for everyone" stays on
- Find out where temporary chat lives, so you can reach it when you need it
- On a company account, note which of these your admin has already decided for you

Do this first. Everything you type from now on is covered by whatever you set here.

### 2. Write your custom instructions

Under **Settings → Personalization**, fill in what ChatGPT should always know about you. Cover three things:

- What you do, in one sentence, so it stops explaining your own field back to you
- Who you usually write for
- How you want answers: language, length, tone, and whether it should ask before assuming

A line worth including verbatim: *If my request is ambiguous, ask before you answer.*

### 3. Try the reasoning control

Ask the same question twice, once on the default setting and once with reasoning raised. Use something with a few steps, for example:

> Our team of six spends about four hours a week on manual status reporting. Walk me through whether it is worth automating, including what could go wrong.

Note what actually differs: the time it takes, the structure, and whether the second answer raises anything the first missed.

### 4. Create your first project

Make a project for one of the candidates from your Lesson 1 shortlist.

- Give it a name you will recognise next month
- Add project instructions describing the recurring context
- Upload one reference file if you have one that is not confidential

### 5. Check what it remembers

Ask it directly:

> What do you know about me so far?

Read the answer. Delete anything you did not intend to save.

## Success Criteria

- [ ] Data controls reviewed and consciously decided
- [ ] Custom instructions filled in with all three elements
- [ ] The same question compared across two reasoning settings
- [ ] One project created with instructions
- [ ] Memory reviewed and cleaned

## Troubleshooting

**"I do not see these settings."**
The interface changes regularly and options differ by plan and country. Search the settings for the keyword rather than following a screenshot. On a managed company account, some settings are locked by your admin, which is itself worth noting.

**"My company account has options I do not recognise."**
Note them and ask your admin afterwards. Workspace-level settings override anything you choose personally.

**"Both reasoning settings gave me a similar answer."**
That happens with simple questions and is useful to see. Try something genuinely multi-step, such as comparing three options against four criteria.

**"I have nothing to upload that is not confidential."**
Skip the file. The project instructions matter more than the attachment.
